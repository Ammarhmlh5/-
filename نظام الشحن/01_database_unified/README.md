# قاعدة بيانات نظام الشحن والإدارة الموحدة

قاعدة بيانات PostgreSQL واحدة تجمع جداول **نظام الشحن** وجداول **الإدارة** (الموظفون + الصلاحيات RBAC + الفروع والأقسام) في مخطط متكامل، مع الإبقاء على جداول التكامل مع ERPNext.

## التشغيل

```bash
copy .env.example .env
docker compose up -d
```

- المنفذ الافتراضي: `5434`
- قاعدة البيانات: `shipping_admin`
- المستخدم الافتراضي: `admin` / `Admin123!`

## الجداول

### (1) الإدارة والصلاحيات
| الجدول | الوصف |
|--------|-------|
| `branches` | الفروع/المكاتب (الصين، اليمن) |
| `departments` | الأقسام داخل كل فرع |
| `employees` | سجل الموظفين |
| `users` | حسابات المستخدمين الموحدة |
| `platform_roles` | الأدوار (مرآة مزامنة من ERPNext) |
| `user_branch_roles` | تعيينات الأدوار حسب الفرع |
| `permission_matrix` | مصفوفة الصلاحيات لكل دور |
| `acl_sync_log` | سجل مزامنة الصلاحيات من ERPNext |
| `refresh_tokens` | جلسات رموز التحديث |

### (2) الشحن والعمليات
| الجدول | الوصف |
|--------|-------|
| `warehouses` | المستودعات |
| `customers` | العملاء |
| `shipments` | الشحنات |
| `shipments_items` | بنود الشحنة |
| `containers` | الحاويات |
| `tracking_events` | أحداث التتبع |
| `shipping_lines` | شركات الشحن |
| `ports` | الموانئ |

### (3) المالية
| الجدول | الوصف |
|--------|-------|
| `invoices` | الفواتير |
| `payments` | المدفوعات |

### (4) المراجعة والتكامل
| الجدول | الوصف |
|--------|-------|
| `audit_logs` | سجل المراجعة العام |
| `integration_channels` | قنوات التكامل (ADMIN/MARKET/SHIPPING) |
| `integration_credentials` | بيانات اعتماد التكامل (بدون أسرار) |
| `integration_key_events` | دورة حياة مفاتيح التكامل |

## ملاحظات

- الأسرار لا تخزن في القاعدة؛ فقط المراجع (`secret_ref`) والبصمات والهاشات.
- الأدوار تُعرَّف في ERPNext وتُسحب إلى `platform_roles` + `permission_matrix`.
- `users.role` حقل قديم للتوافق الخلفي؛ المصدر الرسمي للصلاحيات هو `user_branch_roles`.
- كلمة مرور admin الافتراضية `Admin123!` مشفرة بـ bcrypt.

## البيئة

- PostgreSQL 15+
- ترتيب إنشاء الجداول يضمن سلامة المفاتيح الأجنبية تلقائياً.
